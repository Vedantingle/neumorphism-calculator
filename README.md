# Neumorphism Calculator 🧮

The **Neumorphism Calculator** is a modern UI calculator designed using **neumorphic design principles**, giving elements a soft, extruded appearance.  
It supports both **Light Mode and Dark Mode**, allowing users to switch themes dynamically.

This project focuses on **UI aesthetics**, **CSS variables**, and **JavaScript logic handling**.

---

## ✨ Key Features

- Neumorphic UI design (soft shadows & depth)
- Light and Dark mode toggle
- Responsive calculator layout
- Real-time calculations
- Percentage, clear, and backspace support
- Smooth button interactions and transitions

---

## 🛠 Tech Stack

- **HTML5** – Structure
- **CSS3** – Neumorphism styling & theming
- **JavaScript (Vanilla)** – Calculator logic & theme toggle

No frameworks. Pure fundamentals.

---

## 🎨 Design Concept

Neumorphism blends:
- Subtle shadows
- Soft highlights
- Minimal color contrast  

The calculator UI uses **CSS variables** to dynamically switch between light and dark themes without reloading the page.
